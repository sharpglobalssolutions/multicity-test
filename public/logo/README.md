# Site logo

Drop your logo file in this folder using one of these exact names — the
header picks it up automatically, no code changes needed:

- `logo.svg` (preferred — scales perfectly at any size, smallest file size)
- `logo.png` (used only if `logo.svg` isn't present; export at 2x the
  display size for a crisp look on retina screens, e.g. ~320×80px for an
  image that displays around 160×40px, transparent background)

Until a file is added here, the header falls back to the existing
"MultiCityExperts" text wordmark — nothing breaks in the meantime.
